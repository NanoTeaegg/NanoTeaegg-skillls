## 5. 全局交互模式

> 跨页面复用的模式，在这里统一定义，各界面引用即可，无需重复描述。

### 5.1 通知与反馈

| 类型 | 触发场景 | 展示形式 | 持续时间 / 关闭方式 |
|------|----------|----------|---------------------|
| 成功提示 | 操作成功 | Toast（右上角） | 3 秒自动消失 |
| 警告提示 | 不可逆操作前确认 | Modal 对话框 | 用户主动关闭 |
| 错误提示 | 请求失败 | Toast 或行内提示 | |
| 加载状态 | 异步请求进行中 | Spinner / Skeleton | 请求完成自动结束 |

### 5.2 不可逆操作确认机制

> 删除、清空、不可撤销的提交等操作，统一走以下确认流程：

1. 用户点击危险操作按钮 → 弹出确认 Modal
2. Modal 显示：操作后果说明 + 「取消」（默认焦点）+ 「确认删除」（危险色）
3. 用户点击确认 → 执行操作，同时禁用按钮防止重复提交
4. 完成后给出成功/失败 Toast

### 5.3 权限与鉴权

| 场景 | 处理方式 |
|------|----------|
| 未登录访问需鉴权页面 | 重定向到登录页，登录成功后回跳 |
| 权限不足 | 显示「无权限」说明页，提供返回或联系管理员的引导 |
| 登录态过期 | <刷新 token 或重新登录策略> |
