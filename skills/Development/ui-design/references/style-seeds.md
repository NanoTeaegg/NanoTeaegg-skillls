# 产品 UI 风格种子

产品气质关键词 → 初始 Token 方向映射。

用于 ui-design 访谈的第三步：用户描述产品气质后，快速匹配风格方向并展示 token 默认值供确认，再按平台 reference 细化。

**与 web-design/style-seeds 的区别**：本文件面向产品应用（后台/App/工作台），不是营销展示页。视觉克制度更高，动效档位更保守，信息密度更大。

---

## 1. 效率工具 · Efficiency

**关键词**：专业、效率、数据、扫描、工作台
**代表产品**：Linear、Vercel、GitHub、Figma（工作区）
**适用**：开发者工具、项目管理、数据分析、内部后台

```
色板（亮）：
  背景      #FAFAFA     表面  #FFFFFF
  边框      #E5E7EB     强边框 #D1D5DB
  主色      #5E6AD2 (蓝紫) 或 #0070F3 (纯蓝)
  文字主    #111827     文字次 #6B7280
  成功      #16A34A     错误  #DC2626

色板（暗）：
  背景      #09090B     表面  #18181B
  边框      #27272A
  主色      #818CF8     文字主 #F4F4F5  文字次 #A1A1AA

字体：Inter + JetBrains Mono（代码）
圆角：按钮 6px  卡片 8px  弹窗 12px
信息密度：紧凑（compact，行高 1.4）
动效档位：L1（hover + 轻入场，无滚动动效）
```

## 2. 企业管理 · Enterprise

**关键词**：稳重、信任、专业、大屏、批量操作
**代表产品**：Salesforce、ServiceNow、SAP Fiori、企业 ERP
**适用**：企业 SaaS、审批系统、HR/财务系统、管理后台

```
色板（亮）：
  背景      #F5F5F5     表面  #FFFFFF
  边框      #D9D9D9     主色  #1677FF (Ant Design 蓝) 或 #2563EB
  文字主    #1A1A1A     文字次 #595959

色板（暗/少用，企业产品多不支持）：
  如需支持：背景 #141414  表面 #1F1F1F

字体：Noto Sans SC + Inter（中英混排）
圆角：按钮 4px  卡片 4-6px  弹窗 8px（偏小，体现严肃感）
信息密度：标准（standard，行高 1.5）
动效档位：L1（仅 hover，无装饰性动效）
特别注意：表格是核心，必须定义密度（standard/compact/comfortable）
```

## 3. 金融科技 · Fintech

**关键词**：信任、安全、精确、数字感、简洁
**代表产品**：Revolut、Wise、Stripe Dashboard、Robinhood
**适用**：支付、银行、交易、资管、记账

```
色板（亮）：
  背景      #FFFFFF     表面  #F9FAFB
  主色      #0070F3 (蓝) 或 #1677FF
  强调/利润  #16A34A (绿) 亏损 #DC2626 (红)
  文字主    #111827     数字强调 #1A1A1A (更粗/更深)

色板（暗）：
  背景      #0F172A     表面  #1E293B
  主色      #3B82F6     成功 #22C55E

字体：
  数字字体  Tabular Number（等宽数字）必须开启 font-variant-numeric: tabular-nums
  标题/UI   Inter / DM Sans
圆角：按钮 8px  卡片 12px  弹窗 16px（偏大，体现现代感）
信息密度：标准
动效档位：L1（数字变化可用 count-up 动效，其余克制）
```

## 4. 医疗健康 · Healthcare

**关键词**：信任、干净、温和、安全感、辅助性
**代表产品**：医院信息系统、健康 App、诊断平台
**适用**：医疗 SaaS、健康追踪、患者管理

```
色板（亮）：
  背景      #F0F9FF     表面  #FFFFFF
  主色      #0EA5E9 (天蓝) 或 #10B981 (绿意)
  警告      #D97706     错误  #DC2626（与危险诊断区分）
  文字主    #0F172A     文字次 #475569

色板（暗/通常不做）：
  若需要：参考效率工具暗色，主色换为 #38BDF8

字体：Noto Sans SC（中文正文行高≥1.7）+ Inter
圆角：按钮 8px  卡片 12px  弹窗 16px
信息密度：宽松（comfortable，不给使用者压迫感）
动效档位：L1（诊断/数据展示场景，无装饰动效）
特别注意：状态颜色语义不能与医学颜色（红=出血、绿=安全）冲突
```

## 5. 创意协作 · Creative

**关键词**：创意、个性、活泼、色彩丰富、灵感
**代表产品**：Figma、Miro、Notion、Framer
**适用**：设计工具、白板协作、知识管理、内容创作平台

```
色板（亮）：
  背景      #FFFFFF     表面  #F5F5F5
  强调色    多彩（可用 CSS 变量支持多主题切换）
  默认主色  #0D99FF 或 #7C3AED (紫)
  文字主    #1A1A1A

字体：Plus Jakarta Sans / DM Sans（活泼感）或 Instrument Serif（高级感）
圆角：按钮 8-12px  卡片 16px  弹窗 20px（偏大偏圆，活泼感）
信息密度：宽松
动效档位：L2（滚动入场、hover 变化，但不用 WebGL）
特别注意：多用户协作需定义用户色（avatar 颜色矩阵）
```

## 6. AI 产品 · AI Product

**关键词**：科技、智能、流动、未来、对话
**代表产品**：Claude、ChatGPT、Cursor、Cohere
**适用**：AI 助手、LLM 应用、AI SaaS 工作台

```
色板（亮）：
  背景      #FAFAFA 或 #FFFFFF
  主色      #CC785C (Claude) / #10A37F (GPT) / 品牌定制
  中性      #D1D5DB 边框   #6B7280 次文字

色板（暗，AI 产品多支持）：
  背景      #1A1A1A 或 #0D0D0D
  表面      #262626
  主色降饱和 亮色版的 80% 亮度

字体：Inter / Geist（现代感，等宽代码 JetBrains Mono 必须）
圆角：按钮 8px  Chat Bubble 16-20px  弹窗 12px
信息密度：宽松（对话场景，行高≥1.7）
动效档位：流式文字（streaming）必须有光标动画；其余 L1
特别注意：代码块、Markdown 渲染是核心组件，必须单独规范
```

## 7. 消费 B2C · Consumer

**关键词**：温暖、友好、包容、场景感、年轻
**代表产品**：Airbnb、小红书、得物、Keep
**适用**：电商、社区、旅行、运动健康

```
色板（亮）：
  背景      #FFFFFF     表面  #F7F7F7
  主色      品牌色（橙/红/绿，饱和度高）
  典型      Airbnb #FF5A5F   Keep #47D7AC

字体：中文圆润感（Noto Sans SC）/ 英文 Nunito / DM Sans
圆角：按钮 24px（Pill）  卡片 16px  弹窗 20px
信息密度：宽松（图片多，文字少）
动效档位：L2（卡片 hover、图片轮播、Skeleton 加载）
特别注意：图片是核心，需定义图片比例（1:1 / 4:3 / 16:9）和占位规则
```

## 使用方式

1. 用户在访谈时描述气质方向（如"整体偏稳重专业，用于内部审批系统"）
2. 对照上表找到最匹配的种子（"企业管理"）
3. 展示对应的 token 默认值，问用户："主色和圆角方向是否对齐？"
4. 用户确认后，以此为基础进入 design-token-template.md 填写完整 token 表
5. 如果用户说"做成类似 XX 产品"，先查 `references/design-systems/` 有无该品牌预置
